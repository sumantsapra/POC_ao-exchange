# accordion-photo

Custom **accordion** block. Purpose: Principles/values lists where each item has a backdrop image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = item title; cell 2 = backdrop picture followed by the description paragraph(s). The block adds the 01., 02. ... numbers.
