# cards-gradient

Custom **cards** block. Purpose: brand gradient definitions painted from named colour stops.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per gradient; one cell: gradient name as h3, then a bulleted list of colour-stop names in order (e.g. Process Blue, Bright Blue, White).
