# cards-swatch

Custom **cards** block. Purpose: colour palette swatches painted from their Hex value with a Copy HEX control.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per swatch; cell 1 optional texture image (leave empty for flat colours); cell 2 colour name as h3, then paragraphs "Hex: 0091D2", "RGB: 0/145/210", "CMYK: 100/15/0/0", "Pms: Process Blue C/U" (omit values for special-finish tiles).

## Supported variations

No variations.
