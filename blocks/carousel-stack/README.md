# carousel-stack

Custom **carousel** block. Purpose: Scroll-told media sequences (photo/video + one-line caption).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = link to the video (any link is treated as a video, e.g. extension-less storage URLs) or a picture; cell 2 = caption paragraph, accent phrase in <em>.

## Supported variations

No variations.
