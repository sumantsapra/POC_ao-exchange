# hero-scrollvideo

Custom **hero** block. Purpose: Tagline/brand-idea moments with a pinned lockup over scroll-scaled video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = link to the MP4 (or a picture); row 2 = eyebrow (<strong> paragraph) + caption pairs before the heading, the heading (title), then eyebrow + caption pairs after it; when there are 2+ pairs after the heading, the last one is the outro caption.
