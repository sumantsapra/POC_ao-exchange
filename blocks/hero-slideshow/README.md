# hero-slideshow

Custom **hero** block. Purpose: Landing-page intro heroes with a cycling photo/video stack and title.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background media (pictures, cycled top first, plus an optional link to an MP4 used as the final looping layer); row 2 = H1 title and a paragraph of links (first link = scroll-down control with arrow, second link = skip pill).

## Supported variations

No variations.
